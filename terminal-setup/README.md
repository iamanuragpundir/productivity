# 💻 Terminal Setup for macOS

A supercharged terminal environment with `iTerm2`, `zsh`, `Oh My Zsh`, `Powerlevel10k`, `tmux`, and a bunch of useful developer tools.

## 🚀 Features

- ⚡ Zsh with Oh My Zsh & Powerlevel10k
- 🧠 Smart navigation with `zoxide` and `fzf`
- 📁 Pretty file browsing with `exa`
- 🔍 Supercharged search with `ripgrep`
- 🧠 Command correction with `thefuck`
- 🧱 Tmux auto-start
- 🧰 Developer-friendly defaults

## 🛠️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/terminal-setup.git
cd terminal-setup
chmod +x setup.sh
./setup.sh
